Drop a Kaaba photo here named "kaaba.jpg" to use it as the hero image.

Recommended:
- Filename: kaaba.jpg  (or kaaba.png — then update LandingPage.jsx to /kaaba.png)
- Dimensions: ~1600 x 800 (any wide rectangle works)
- Format: JPG, PNG, or WebP

If no kaaba.jpg is present, the landing page automatically falls back to an
SVG illustration so the design still looks correct.

Free Kaaba photos:
- https://www.pexels.com/search/kaaba/
- https://unsplash.com/s/photos/kaaba
- https://commons.wikimedia.org/wiki/Category:Kaaba
